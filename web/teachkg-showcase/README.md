# TeachKG Showcase

四块展示：单课复习、课堂知识图谱、知识导图、资产库。

## 启动

```bash
cd web/teachkg-showcase
npm install
npm run sync-data   # 从仓库根 data/kg、data/viz 生成 public/data
npm run dev         # 默认 http://127.0.0.1:5174
```

`npm run dev` / `build` 会先跑 `sync-data`（`predev` / `prebuild`）。

课程默认可用环境变量覆盖：

```bash
TEACHKG_COURSE="离散数学(图论+数理逻辑与集合论)" npm run sync-data
```

## 路由（课内）

| 路径 | 说明 |
|------|------|
| `/course/:id` | 课门户 |
| `/course/:id/apps/review/:lectureId` | 单课复习 |
| `/course/:id/kg/course` | 课堂知识图谱 |
| `/course/:id/mindmap` | 知识导图 |
| `/course/:id/assets/:lectureId` | 资产库 |

离线构建与导出脚本已移出本仓库（见 VAT-KG）。

## 学生掌握思维导图

AI-Teaching 现有 iframe 路径 `/course/:courseId/kg/course?embed=ai-teaching` 保持不变。掌握视图仅由 `/mindmap` 的 `mastery_view=1` 显式启用，普通图谱入口保持原页；身份验证后学生读取个人分数，教师和助教读取匿名班级均值。学生导图数据为 `public/data/courses/离散数学(图论+数理逻辑与集合论)/mindmaps/student_mastery_course.json`，保留原始整课导图文件不变。

掌握分数通过前端同源 `GET /api/student-mastery?course_id=<Canvas 课程 ID>` 读取。Vite 服务端把请求及 `X-KG-Token` 转发到 `AI_TEACHING_API_URL/api/knowledge-links/courses/<课程 ID>/mastery`；AI-Teaching 端须先部署对应的只读接口。若接口不可用，页面明确提示且以「暂无记录」显示，不伪造分数。staging 的 `AI_TEACHING_API_URL` 必须指向 staging AI-Teaching，不能继承生产地址。

学生可按 0–100% 调整节点显示数量。筛选保留层级、根节点及已选节点路径，在主分支间按原始节点数量分配显示名额，并在各分支内优先保留学习中的薄弱节点；`__lecture__` 节点不计入展示和比例。导图沿用上传 ZIP 的原始 `zh`，以便与既有掌握分数对齐；其中少量结构性 `id` 与 `zh` 名称不一致，需在上游数据中另行校正，不能只改显示名称。

## 与旧 HTML 的关系

`web/pipeline-showcase/index.template.html` 与 `data/viz/*.html` 仍可作离线备份；本应用以 JSON + React 为准。


### 掌握思维导图：个人与班级均值

- 普通课程图谱入口保持 KgPage；首页通过 `/mindmap` 页面嵌入掌握视图，使用 `mastery_view=1&compact=1`。
- 掌握度接口按已验证的签名身份决定范围：学生只读本人；助教/教师只读当前课程在读学生的匿名均值。班级分母为当前 Canvas 在读学生数，未记录学生按 0 计，不纳入助教练习记录。
- `knowledge_points` 提供数据库 ID 与完整知识点名称的对应关系；导图按 ID 或唯一中文名称绑定，不做模糊匹配。0 分与无记录分别显示，颜色由薄弱的红色过渡至已掌握的绿色，掌握越高圆点越小。
- 保留原始树结构的逐节点 +/−、双击和键盘展开/收起，顶栏可逐层或全部展开。折叠按原始节点路径记录，百分比筛选不会改写知识点身份。


### ZIP 参考项目的子树空间优化布局

布局源为用户提供的 `business-handoff-color-only.zip`，SHA-256 为 `48ba4fcd86527e52c1fa0a483b2fd13ecb65345164777e99f4dd90ee871a070e`。`src/lib/kg/packedMindmapLayout.mjs` 移植其中 `business-handoff/layout.py` 的算法：

- `blocks` / `leaf_rows`：混合子节点中超过四个叶节点进入两列布局；按实际字体测量和换行计算矩形尺寸。
- `needed` / `Layout.subtree`：测量并布置整棵子树，保留节点层级与次序。
- `chapter_plan`：以真实节点矩形轮廓装箱，章节可利用前一子树的空隙；保留原版偏移候选、200 状态束搜索、首章锚点多样性、阅读顺序与右侧前向约束。
- 按装箱后的树高选择左右分支并叠放短分支；连线采用原版候选曲线和碰撞检测。

集成差异仅涉及交互数据与掌握度控件：以原始路径区分重复 ID，不采用参考导出器的跨章节点合并；将分数圆点和折叠按钮纳入矩形宽度并避免挤占父分支。折叠或筛选后重新装箱，分数更新不会触发无关布局计算。

束搜索在 Web Worker 中执行，重复展开状态复用最近的布局。`fixtures/zipPackedLayout.golden.json` 的预期结果由原 ZIP 的 Python `chapter_plan` 独立执行生成；测试同时检查整课展开与折叠状态的节点完整性及矩形不重叠。


掌握导图工具栏提供显示比例、全部展开和重置控件；逐节点加减号、双击和键盘展开折叠、滚轮缩放、拖动仍可使用。仪表盘紧凑模式的详情改为选中后浮层显示，画布不再因详情挤压。个人视图以紫色箭头连接低于 2.5 的已记录节点（含 0 分）；按原始分册/章节顺序逐章遍历，章内深度优先，先学完当前节及其全部后代，再进入下一节，仅连接当前可见圆点。全班平均视图不生成个人学习路径。掌握圆点扩大最小半径、强化分数对比，节点文字的字号、折行宽度与 ZIP 子树布局保持不变。


掌握导图默认展开到章下的节（如“图的定义”）。学习路径按先序深度优先遍历每章，只连接低于 2.5 的可见已记录节点。`__section__`、`__topic__` 等导入概念节点允许按规范实体或明确标题查询资源；仅课程、分册、章节、课次包装节点不查询概念资源。

同步运行中 staging `mmkg-frontend-notes-v10:local` 的前端与资源关联代码，以已有 staging 同步提交 ed077b2 为三方合并基线，保留 main 后续代码、掌握功能与角色校验。课程数据由部署目录提供，不随本 PR 提交 staging 快照。资源查询采用最新索引规范化、严格主题匹配、跨课次检索和资源跳转栏；视频元数据服务不可用时保留 MMKG 已有引用及真实起点，不伪造摘要。debug 独立数据挂载包含 889 张资源卡；浏览器验证“子图”显示 4 条资源，相关视频按钮进入该知识点视频列表。


知识图谱入口 `/kg/course` 始终使用原有 KgPage。掌握视图仅由首页嵌入地址的 `mastery_view=1` 显式启用，不再因学生身份替换知识图谱或普通思维导图页面。


掌握导图工具栏“全部展开”恢复 100% 比例并展开全部层级，清除单节点折叠覆盖、适配画布；“重置”恢复默认节层（87 个节点）、100% 比例及初始缩放/平移，并清除选中节点及详情浮层。

学生学习路径的线宽、虚线间隔及箭头头部均使用导图 SVG 坐标，随导图一起缩放；不再使用固定屏幕线宽。助教班级平均视图保持不绘制路径。


掌握视图工具栏增加“显示节点文字”开关，关闭时仅保留课程总标题，分册、章、节及以下名称和文字占位全部移除，按掌握圆点及折叠按钮的实际尺寸重新装箱、连接；保留分数、箭头、折叠及悬停名称，节点数量与筛选结果不变，重置恢复名称和原布局。首页节点详情改为随内容收缩的圆角浮动卡片，突出标题、分数、状态及进度，提供右上角关闭和并排练习/视频入口；无动画时隐藏空动画栏目，资源列表自适应滚动，并预留底部悬浮按钮空间。普通知识图谱和非掌握导图沿用各自详情布局。


### 代码与部署数据的交接

最终部署由 fencaolin 在其现有部署目录同步代码后执行。本 PR 不携带从运行中 staging 复制的资源库、pipeline、章节/讲次导图、note_match 和 summaries 等课程数据快照；这些数据继续以部署目录为准，避免代码合并覆盖较新的内容。仅保留掌握视图新增且直接加载的 `mindmaps/student_mastery_course.json`（课程树结构，不含学生分数）以及布局测试 oracle。

同步代码后，在部署目录使用已有数据流程执行 `npm run sync-data`，确认课程资源索引与讲次导图仍来自该目录，再沿用既有 Docker Compose 构建和启动流程。掌握视图的新增 `student_mastery_course.json` 应保留；实际掌握分数由已验证身份的 API 动态返回。不要用本 PR 的回退提交去覆盖部署目录的自有数据。debug 环境将课程数据挂载在工作树之外，用同一代码验证最新资源链接。


### 自由 / 严格布局与节点详情

掌握视图默认使用严格布局，保留 ZIP 的子树装箱。工具栏“自由布局”开启后，对当前同一组筛选、折叠后的节点与父子边运行力导向模拟（沿用旧首页的斥力、边弹簧、中心引力及速度阻尼，加入实际文字尺寸避让），不恢复旧首页的 60 节点限制、旧分数圆点或旧边集。可单独拖动节点，拖动位置固定到重置；连线和学生个人路径箭头随节点实时更新。切换布局保留比例、文字开关、折叠和选中节点，重置清除拖动位置；严格布局坐标独立保留。助教仍不显示个人路径。

两种布局均展示新的掌握分数圆点，可按比例筛选、折叠、隐藏文字（始终保留课程标题且移除其他名称占位）。力学模拟初始自动适配；手动缩放、平移或拖动节点后固定视窗，避免视窗随拖动跳动。

掌握详情从部署目录的 `pipeline/kg_processed_course.json` 与 `entity_definitions.json` 按精确 ID 或唯一名称/别名读取规范名、别名和实体定义；定义可展开/折叠，公式沿用 LaTeX 渲染，缺失定义明确显示空状态，不从重要性文字推断。详情浮层左边界支持鼠标/触摸拖宽和键盘左右键调宽，宽度保存于浏览器，并受画布宽度约束。
