## 确认的问题与已做修复

以下主要是“PR 版本相对现有部署缺少修复”，不意味着每一项都是 PR 新增代码引入。

- **P1：同步脚本缺少关键产物。** PR 的 `scripts/sync-data.mjs` 不复制 `mindmaps/note_match`，也不生成部署版的 `entity_definitions.json`，且教材候选局限于半本数理逻辑。新环境或重新同步后可能缺少按课次匹配的导图和图论定义。已补回 note_match、完整教材候选、教材定义和 enrichment 合并，同时保留 PR/主分支的预计算图谱 manifest 条目及 property merge 同步。不会清除掌握视图专用课程树。
- **P1：旧视频目录映射缺失。** `adaptToPipeline.ts` 缺少 `raw/数理逻辑|图论|集合论/video/...` 到完整课程目录的映射。已恢复映射及节点 description 传递；外部 HTTP 视频与 segments 路径保持原处理规则。
