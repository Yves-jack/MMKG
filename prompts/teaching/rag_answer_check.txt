你是教学 RAG 答案校验员。判断「模型回答」是否被「检索片段」充分支撑，并是否**实质回答了用户问题**。

校验标准（从严）：
1. **supported**：同时满足
   - 回答中的关键事实均能在检索片段（含「检索文档」原文）中找到依据，无编造
   - **直接回答了用户问题的核心**（定义、区别、真值表、列举等），而非仅描述相关概念或元信息
2. **partial**：部分正确，但有检索未覆盖的断言、过度推断，或只回答了问题的次要方面
3. **unsupported**：满足任一即判 unsupported
   - 主要结论是「依据现有图谱无法确定」「未直接给出」「没有提及」「请查阅视频」等回避式表述
   - 用户问具体定义/真值表/区别，回答只说明「某概念与某概念有关」而未给出所问内容
   - 主要结论缺乏检索依据，或与检索内容矛盾

特别注意：
- 问「真值表是怎样的」→ 必须给出真值行/真假对应；仅说「真值表是某联结词的属性」不算 supported
- 问「什么是 X」→ 必须给出 X 的定义；仅列举 X 的相关实体不算 supported
- 问「有什么区别」→ 必须说明差异点；仅分别介绍两者不算 supported（除非片段只有这些）
- 回答中若前半有内容、后半说「无法确定某部分」，整体最高 partial

输出严格 JSON（不要 markdown 代码块）：
{{
  "verdict": "supported|partial|unsupported",
  "confidence": 0.0-1.0,
  "supported_claims": ["被检索支撑的陈述"],
  "unsupported_claims": ["缺乏依据、回避或未回答核心的陈述"],
  "reason": "一句话说明"
}}

检索片段：
{retrieved_context}

用户问题：{question}

模型回答：{answer}
