你是知识图谱三元组抽取专家。这是对同一段课堂文本的**补漏抽取**（第二轮，仍须严格依据原文）。

首轮可能漏抽。请**重新按句扫描**全文，并对照「知识点列表」，补上仍遗漏、且「教材子图 / 已抽取增量」都未覆盖、**且有课堂原文依据**的概念层关系。

## 强制流程
1. 逐句对照下方触发清单；一句多关系则多条
2. 逐条检查知识点：若原文已讲到组成/归属/依赖等，但已抽取中没有对应边，必须补
3. 只输出首轮**尚未出现**的新全名 SPO
4. 教材子图为空/很少、或首轮几乎为空时，更要主动按原文补全
5. **禁止**补充原文未提及、也未明确蕴含的关系（体系补全由独立的 KG 补全步骤负责）
6. 确无遗漏才输出 {{"triples": []}}——若文中仍有定义/分类/属性/同义等未入库，禁止空输出

## 触发清单（命中且未在「已抽取」中 → 必须补）
- 是/属于/称作/一种 → belong_to
- 部分/组成/包含/基本概念（相对体系） → part_of
- 依赖/基于/基础/移植自/推广自 → depend_on
- 又称/即/也叫/对应 → synonym_of
- 具有/用…表示/翻译成/只能/不能/真值条件 → property_of（「具有*」须 object_to_subject；S=属性 O=拥有者）
- 个体函数/个体常项/个体变元（变量）→ 子→父 belong_to 或 part_of（挂到个体）
- 论域/个体域=所有个体的全集/集合 → 个体 belong_to 论域
- 分为一元/二元/n 元；零元谓词即命题；特殊情形/推广 → 分类或推广关系
- 约束变元/自由变元、改名规则等新概念 → 相应关系

## 约束（同首轮）
- 已知教材实体须原样复制全名；禁止编号实例、证明链、人名例题、字母串实体
- property_of：A 是 B 的属性（S=属性侧，O=拥有者）；「具有*」须客→主拼读，禁止 subject_to_object；少用 related_with
- **每条边 context 必须是课堂原文连续摘录**（可在原文中定位）
- concrete_relation 1–8 字；补输出字段同首轮 JSON schema
