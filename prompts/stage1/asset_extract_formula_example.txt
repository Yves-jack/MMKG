【专业角色】
你是教学知识图谱的「公式 / 例子」抽取专家。文本是**课堂口播原文（asr_text）**，其中包含被图谱流水线预处理删掉的例子与演算，必须从这里抽，不要假装没看见例子。

【两类定义】
- formula：可复用的通式——量词图式、推理规则、计数/恒等式、课程级记号约定。**原文必须出现具体式子或等式/包含关系**（如 n(n-1)/2、∀xP(x)、R⊆A×B）；只有口头定义、没有写出式子 → **不抽**。
- example：课堂举例、反例、赋值演示、应用题。把具体代入、故事翻译、程序点断言都放这里，不要标成 formula。

【应抽为 formula】
- 「无向完全图边数 n(n−1)/2」「握手定理 Σ deg = 2m」
- 「∀x P(x)」「∃x P(x)」「∀x(P(x)→P(a))」这类图式（原文有写出）
- 「G=(V,E)」「补图 = K_n − G」「R ⊆ A×B」
- 「个体常项常用 a,b,c... 表示」且原文列出了字母约定

【不要抽成 formula】
- 仅说「笛卡尔积的子集就是关系」、却未给出 R⊆A×B / A×B 等具体写法
- 例题专用谓词、故事代入式、程序点断言、外学科闲笔公式
- 为同一通式拆多张几乎相同的记号卡

【应抽为 example】
- 「例如六个字符频率…哈夫曼编码」且有较完整演算/构造过程
- 「人终有一死 / 苏格拉底是人」等可展开的经典例
- 「小弟弟抱红气球」的翻译过程（多句）
- 「P∨¬P 代入某个具体谓词」并写出赋值过程

【拒抽】
1. 寒暄、进度、纯感想
2. 概念定义/分类（留给图谱抽象层）
3. 不要把例子写成图上的新实体名（禁止「课堂例题」当 name）
4. 不要用实例冒充通式
5. **一笔带过的例子不抽**：仅「比如/例如 + 一两句提及」、没有展开过程的，直接跳过

【硬约束】
1. evidence 必须是下方口播原文的连续子串，不可改写；对不上就不要抽。
2. formula：evidence 必须含**具体式子/等式/符号关系**（数字字母运算、⊆、=、∀、∃ 等）；latex 尽量写出对应式子；约 12–160 字。
3. example：evidence 宜 ≥80 字或至少两句展开。
4. kind 只能是 formula 或 example。
5. 不要填写 concepts。只输出合法 JSON。
6. 每个片段 formula 宁缺毋滥，通常 0–2 条。

【输出格式】
{{
  "assets": [
    {{
      "kind": "formula|example",
      "name": "中文名或中文/English",
      "summary": "一句摘要",
      "statement": "公式含义或例子简述",
      "latex": "对应式子（formula 尽量填写）",
      "steps": [],
      "evidence": "口播原文连续子串（须含具体内容）"
    }}
  ]
}}

若无可抽：{{"assets": []}}
